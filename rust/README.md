# kvrail (Rust)

Native CLI companion to the Python package. v0.0.1 ships `kvrail doctor`,
a zero-dependency check that a Mac is ready for RDMA over Thunderbolt 5.
The data-plane crates (wire protocol, slab store) will live here as the project grows.

    cargo install kvrail
    kvrail doctor

Docs and source: https://kvrail.org / https://github.com/kvrail/kvrail
